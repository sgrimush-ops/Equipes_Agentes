Laboratório de Carga & Atualização de Tabelas

Aprenda a atualizar tabelas no Totvs Consinco (Oracle) usando planilhas e SEQPRODUTO como chave mestre

Arquitetura

As 3 Tabelas de Pontas de Gôndola / Pontos Extras

No ERP Totvs Consinco, uma ponta de gôndola ou ilha promocional é estruturada em 3 níveis hierárquicos obrigatórios:

1. MRL_PONTOEXTRA (Capa do Ponto)
Cadastra a localização física na loja. Chave: SEQPONTOEXTRA (ex: 203 = Ponta de Bebidas).
▼
2. MRL_PONTOEXTRAPRODUTO (Produto no Ponto)
Vincula quais produtos podem estar naquela ponta. Chave: (SEQPONTOEXTRA, SEQPRODUTO).
▼
3. MRL_PONTOEXTRAPRODUTOEMPRESA (Regras por Loja)
Onde ficam o Estoque Mínimo, Máximo e Vigência para cada filial. Chave: (SEQPONTOEXTRA, SEQPRODUTO, NROEMPRESA, SEQVIGENCIA).
Chave Primária

Por que usar SEQPRODUTO como Chave?

  • Imutabilidade: Descrições de produtos mudam, códigos EAN podem ter trocas de dígitos, mas o SEQPRODUTO é o identificador numérico interno fixo e eterno no Consinco.
  • Integridade Referencial: Todas as tabelas operacionais (MRL_PRODUTOEMPRESA, MRL_PRODEMPSEG, MRL_CUSTODIA) utilizam SEQPRODUTO como chave estrangeira.
  • Velocidade de Processamento: Índices em colunas NUMBER são ordens de magnitude mais rápidos no Oracle do que buscas por texto.
Oracle SQL

Estratégias de Atualização no Oracle

1. MERGE INTO (Padrão Ouro do Oracle)

Executa "Upsert" inteligente: se o registro já existir, faz UPDATE; se não existir, faz INSERT em uma única operação atômica.

2. Blocos Transacionais (UPDATE + INSERT)

Gera comandos diretos de UPDATE para linhas existentes e INSERT para novas, finalizando obrigatoriamente com COMMIT;.

3. Script de Conferência Prévia

Sempre execute um SELECT comparativo antes e após a carga para validar que apenas as lojas e produtos desejados foram afetados.

Segurança

As 5 Regras de Ouro para Nunca Travar o ERP

  1. Nunca faça UPDATE sem WHERE: Isso sobrescreve todas as lojas e todos os produtos do banco!
  2. Formate datas com TO_DATE: Use sempre TO_DATE('2026-08-05', 'YYYY-MM-DD') para evitar erros de formato regional de data.
  3. Sempre crie o vínculo pai primeiro: Não tente inserir na MRL_PONTOEXTRAPRODUTOEMPRESA sem que o produto exista na MRL_PONTOEXTRAPRODUTO.
  4. Não esqueça o COMMIT: Alterações DML seguram locks em linhas da tabela até que o COMMIT ou ROLLBACK seja disparado.
  5. Sem Comentários em Scripts Finais: Se for colar no módulo Consulta Criação do SGI, remova comentários para evitar erros de parser.
