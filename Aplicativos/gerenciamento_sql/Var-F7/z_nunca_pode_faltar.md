# Consulta Criação: z_nunca_pode_faltar (Monitoramento de Ruptura, Estoque Lojas/CDs e Venda Média)

## 1. Objetivo da Consulta
Monitorar de forma preditiva os itens estratégicos ("Nunca Pode Faltar") cruzando:
- **Filtro de Produtos (`LT1`)**: Permite informar múltiplos códigos de produtos separados por vírgula (ex: `1001, 1002, 1055`) ou `0` para todos os produtos ativos.
- **Expurgo Dinâmico de Status (`LT2`)**: Permite expurgar status específicos (ex: `8, 9` para ocultar itens Regulares e Excessos, focando apenas nas rupturas e alertas).
- **Estoque das Lojas**: Saldo físico, reservas e saldo disponível atualizado.
- **Estoque dos CDs**: Saldo disponível total e discriminado por centro de distribuição (CD 15, CD 16 e CD 50).
- **Histórico de Vendas**: Vendas dos últimos 30 dias corridos (excluindo hoje) via tabela analítica oficial `MRL_CUSTODIA` e cálculo de venda média diária.
- **Cobertura e Dias de Estoque**: Projeção de dias de cobertura na loja e na rede (Loja + CD).
- **Parâmetros de Estoque**: Estoque mínimo e máximo padrão de gôndola somados aos mínimos e máximos vigentes de **Pontos Extras / Ilhas**.
- **Pedidos Pendentes e Trânsito**: Pedidos de compra com fornecedor pendentes, pedidos de transferência/suprimento de CD pendentes e cargas em trânsito.
- **Diagnóstico Inteligente de Ruptura**: Classificação automática da situação do item por criticidade.

## 2. SQL Principal
```sql
SELECT * FROM (
    WITH PRODUTOS_FILTRO AS (
        SELECT /*+ MATERIALIZE */
            P.SEQPRODUTO,
            P.DESCCOMPLETA,
            P.SEQFAMILIA,
            FD.PADRAOEMBCOMPRA,
            FD.PADRAOEMBTRANSF,
            FD.FORMAABASTECIMENTO,
            FD.SEQCOMPRADOR,
            NVL(COMP.APELIDO, COMP.COMPRADOR) AS COMPRADOR
        FROM MAP_PRODUTO P
        INNER JOIN MAP_FAMILIA F ON F.SEQFAMILIA = P.SEQFAMILIA
        LEFT JOIN MAP_FAMDIVISAO FD ON FD.SEQFAMILIA = P.SEQFAMILIA AND FD.NRODIVISAO = 1
        LEFT JOIN MAX_COMPRADOR COMP ON COMP.SEQCOMPRADOR = FD.SEQCOMPRADOR
        WHERE (
            NVL(TRIM(:LT1), '0') IN ('0', 'TODOS', '')
            OR INSTR(',' || REPLACE(:LT1, ' ', '') || ',', ',' || TO_CHAR(P.SEQPRODUTO) || ',') > 0
        )
    ),
    CTE_DEPARTAMENTO AS (
        SELECT /*+ MATERIALIZE */
            X.SEQFAMILIA,
            MAX(CASE WHEN Y.NIVELHIERARQUIA = 1 THEN Y.CATEGORIA END) AS DEPARTAMENTO,
            MAX(CASE WHEN Y.NIVELHIERARQUIA = 2 THEN Y.CATEGORIA END) AS SECAO
        FROM MAP_FAMDIVCATEG X
        INNER JOIN MAP_CATEGORIA Y
            ON Y.SEQCATEGORIA = X.SEQCATEGORIA
           AND Y.NRODIVISAO = X.NRODIVISAO
           AND Y.STATUSCATEGOR = 'A'
        WHERE Y.TIPCATEGORIA = 'M'
          AND X.NRODIVISAO = 1
          AND X.STATUS = 'A'
        GROUP BY X.SEQFAMILIA
    ),
    FORNECEDOR_PRINCIPAL AS (
        SELECT /*+ MATERIALIZE */
            F.SEQFAMILIA,
            MAX(F.SEQFORNECEDOR) AS COD_FORNECEDOR,
            MAX(P.NOMERAZAO) AS FORNECEDOR_PRINCIPAL
        FROM MAP_FAMFORNEC F
        JOIN GE_PESSOA P ON P.SEQPESSOA = F.SEQFORNECEDOR
        WHERE F.PRINCIPAL = 'S'
        GROUP BY F.SEQFAMILIA
    ),
    ESTOQUE_CD AS (
        SELECT /*+ MATERIALIZE */
            PE.SEQPRODUTO,
            SUM(GREATEST(0, NVL(PE.ESTQLOJA, 0) + NVL(PE.ESTQDEPOSITO, 0) - NVL(PE.QTDRESERVADAVDA, 0) - NVL(PE.QTDRESERVADARECEB, 0) - NVL(PE.QTDRESERVADAFIXA, 0) - NVL(PE.QTDRESERVADAFISC, 0))) AS ESTQ_DISP_TOTAL_CD,
            SUM(CASE WHEN PE.NROEMPRESA = 15 THEN GREATEST(0, NVL(PE.ESTQLOJA, 0) + NVL(PE.ESTQDEPOSITO, 0) - NVL(PE.QTDRESERVADAVDA, 0) - NVL(PE.QTDRESERVADARECEB, 0) - NVL(PE.QTDRESERVADAFIXA, 0) - NVL(PE.QTDRESERVADAFISC, 0)) ELSE 0 END) AS ESTQ_DISP_CD15,
            SUM(CASE WHEN PE.NROEMPRESA = 16 THEN GREATEST(0, NVL(PE.ESTQLOJA, 0) + NVL(PE.ESTQDEPOSITO, 0) - NVL(PE.QTDRESERVADAVDA, 0) - NVL(PE.QTDRESERVADARECEB, 0) - NVL(PE.QTDRESERVADAFIXA, 0) - NVL(PE.QTDRESERVADAFISC, 0)) ELSE 0 END) AS ESTQ_DISP_CD16,
            SUM(CASE WHEN PE.NROEMPRESA = 50 THEN GREATEST(0, NVL(PE.ESTQLOJA, 0) + NVL(PE.ESTQDEPOSITO, 0) - NVL(PE.QTDRESERVADAVDA, 0) - NVL(PE.QTDRESERVADARECEB, 0) - NVL(PE.QTDRESERVADAFIXA, 0) - NVL(PE.QTDRESERVADAFISC, 0)) ELSE 0 END) AS ESTQ_DISP_CD50
        FROM MRL_PRODUTOEMPRESA PE
        INNER JOIN PRODUTOS_FILTRO PF ON PF.SEQPRODUTO = PE.SEQPRODUTO
        WHERE PE.NROEMPRESA IN (15, 16, 50)
        GROUP BY PE.SEQPRODUTO
    ),
    VENDAS_30D AS (
        SELECT /*+ MATERIALIZE */
            C.SEQPRODUTO,
            C.NROEMPRESA,
            ROUND(NVL(SUM(C.QTDVDA), 0), 2) AS QTD_VDA_30D,
            ROUND(NVL(SUM(C.VLRTOTALVDA), 0), 2) AS VLR_VDA_30D,
            ROUND(NVL(SUM(C.QTDVDA), 0) / 30, 2) AS MEDIA_VDA_DIA
        FROM MRL_CUSTODIA C
        INNER JOIN PRODUTOS_FILTRO PF ON PF.SEQPRODUTO = C.SEQPRODUTO
        WHERE C.DTAENTRADASAIDA >= TRUNC(SYSDATE) - 30
          AND C.DTAENTRADASAIDA < TRUNC(SYSDATE)
          AND C.NROEMPRESA IN (1, 2, 3, 4, 5, 6, 7, 8, 11, 12, 13, 14, 17, 18)
        GROUP BY C.SEQPRODUTO, C.NROEMPRESA
    ),
    PONTOS_EXTRAS AS (
        SELECT /*+ MATERIALIZE */
            PEPE.SEQPRODUTO,
            PEPE.NROEMPRESA,
            NVL(SUM(PEPE.ESTQMINIMO), 0) AS ESTQMINIMO_PE,
            NVL(SUM(PEPE.ESTQMAXIMO), 0) AS ESTQMAXIMO_PE,
            COUNT(DISTINCT PEPE.SEQPONTOEXTRA) AS QTD_PONTOS_EXTRAS_ATIVOS
        FROM MRL_PONTOEXTRA PE
        INNER JOIN MRL_PONTOEXTRAPRODUTO PEP ON PEP.SEQPONTOEXTRA = PE.SEQPONTOEXTRA
        INNER JOIN MRL_PONTOEXTRAPRODUTOEMPRESA PEPE ON PEPE.SEQPONTOEXTRA = PEP.SEQPONTOEXTRA AND PEPE.SEQPRODUTO = PEP.SEQPRODUTO
        INNER JOIN PRODUTOS_FILTRO PF ON PF.SEQPRODUTO = PEPE.SEQPRODUTO
        WHERE PE.STATUS = 'A'
          AND PEPE.STATUS = 'A'
          AND TRUNC(SYSDATE) BETWEEN TRUNC(PEPE.DTAVIGENCIAINICIO) AND TRUNC(PEPE.DTAVIGENCIAFIM)
          AND PEPE.NROEMPRESA IN (1, 2, 3, 4, 5, 6, 7, 8, 11, 12, 13, 14, 17, 18)
        GROUP BY PEPE.SEQPRODUTO, PEPE.NROEMPRESA
    ),
    PENDENTE_COMPRA AS (
        SELECT /*+ MATERIALIZE */
            X.SEQPRODUTO,
            X.NROEMPRESA,
            NVL(SUM(CASE WHEN NVL(X.QTDSOLICITADA, 0) > NVL(X.QTDRECCANC, 0) THEN NVL(X.QTDSOLICITADA, 0) - NVL(X.QTDRECCANC, 0) ELSE 0 END), 0) AS QTD_PEND_COMPRA
        FROM MAXV_MSUPEDIDOSUPRIMREC X
        INNER JOIN PRODUTOS_FILTRO PF ON PF.SEQPRODUTO = X.SEQPRODUTO
        WHERE X.TIPPEDIDOSUPRIM = 'C'
          AND X.NROEMPRESA IN (1, 2, 3, 4, 5, 6, 7, 8, 11, 12, 13, 14, 17, 18)
        GROUP BY X.SEQPRODUTO, X.NROEMPRESA
    ),
    PENDENTE_TRANSF_CD AS (
        SELECT /*+ MATERIALIZE */
            X.SEQPRODUTO,
            X.NROEMPDESTINO AS NROEMPRESA,
            NVL(SUM(NVL(X.QTDSOLICITADA, 0) - NVL(X.QTDEXPCANC, 0)), 0) AS QTD_PEND_TRANSF_CD
        FROM MAXV_MSUPEDIDOSUPRIMEXP X
        INNER JOIN PRODUTOS_FILTRO PF ON PF.SEQPRODUTO = X.SEQPRODUTO
        WHERE X.NROEMPRESA IN (15, 16, 50)
          AND X.NROEMPDESTINO IN (1, 2, 3, 4, 5, 6, 7, 8, 11, 12, 13, 14, 17, 18)
        GROUP BY X.SEQPRODUTO, X.NROEMPDESTINO
    ),
    TRANSITO_CD_LOJA AS (
        SELECT /*+ MATERIALIZE */
            R.SEQPRODUTO,
            R.NROEMPRESA,
            NVL(SUM(NVL(R.QTDTOTTRANSITO, 0)), 0) AS QTD_EM_TRANSITO
        FROM MSU_PSITEMRECEBER R
        INNER JOIN MSU_PEDIDOSUPRIM PS ON PS.NROPEDIDOSUPRIM = R.NROPEDIDOSUPRIM AND PS.NROEMPRESA = R.NROEMPRESA
        INNER JOIN PRODUTOS_FILTRO PF ON PF.SEQPRODUTO = R.SEQPRODUTO
        WHERE PS.SEQFORNECEDOR IN (15, 16, 50)
          AND R.NROEMPRESA IN (1, 2, 3, 4, 5, 6, 7, 8, 11, 12, 13, 14, 17, 18)
          AND NVL(R.QTDTOTTRANSITO, 0) > 0
        GROUP BY R.SEQPRODUTO, R.NROEMPRESA
    ),
    BASE_DADOS AS (
        SELECT /*+ MATERIALIZE */
            PE.NROEMPRESA,
            PF.SEQPRODUTO,
            PF.DESCCOMPLETA AS DESCRICAO_PRODUTO,
            NVL(DEP.DEPARTAMENTO, 'SEM DEPARTAMENTO') AS DEPARTAMENTO,
            NVL(DEP.SECAO, 'SEM SECAO') AS SECAO,
            NVL(PF.COMPRADOR, 'SEM COMPRADOR') AS NOME_COMPRADOR,
            NVL(FP.COD_FORNECEDOR, 0) AS COD_FORNECEDOR,
            NVL(FP.FORNECEDOR_PRINCIPAL, 'SEM FORNECEDOR PRINCIPAL') AS FORNECEDOR_PRINCIPAL,
            NVL(PF.FORMAABASTECIMENTO, '-') AS FORMA_ABASTECIMENTO,
            NVL(PF.PADRAOEMBCOMPRA, 1) AS EMB_COMPRA,
            NVL(PF.PADRAOEMBTRANSF, 1) AS EMB_TRANSF,
            GREATEST(0, (NVL(PE.ESTQLOJA, 0) + NVL(PE.ESTQDEPOSITO, 0) - NVL(PE.QTDRESERVADAVDA, 0) - NVL(PE.QTDRESERVADARECEB, 0) - NVL(PE.QTDRESERVADAFIXA, 0) - NVL(PE.QTDRESERVADAFISC, 0))) AS ESTQ_DISP_LOJA,
            (NVL(PE.ESTQLOJA, 0) + NVL(PE.ESTQDEPOSITO, 0)) AS ESTQ_FISICO_LOJA,
            (NVL(PE.QTDRESERVADAVDA, 0) + NVL(PE.QTDRESERVADARECEB, 0) + NVL(PE.QTDRESERVADAFIXA, 0) + NVL(PE.QTDRESERVADAFISC, 0)) AS ESTQ_RESERVADO_LOJA,
            NVL(PE.ESTQMINIMOLOJA, 0) AS ESTQ_MIN_PADRAO,
            NVL(PE.ESTQMAXIMOLOJA, 0) AS ESTQ_MAX_PADRAO,
            NVL(PX.ESTQMINIMO_PE, 0) AS ESTQ_MIN_PONTO_EXTRA,
            NVL(PX.ESTQMAXIMO_PE, 0) AS ESTQ_MAX_PONTO_EXTRA,
            (NVL(PE.ESTQMINIMOLOJA, 0) + NVL(PX.ESTQMINIMO_PE, 0)) AS ESTQ_MIN_TOTAL,
            (NVL(PE.ESTQMAXIMOLOJA, 0) + NVL(PX.ESTQMAXIMO_PE, 0)) AS ESTQ_MAX_TOTAL,
            NVL(PX.QTD_PONTOS_EXTRAS_ATIVOS, 0) AS PONTOS_EXTRAS_ATIVOS,
            NVL(CD.ESTQ_DISP_TOTAL_CD, 0) AS ESTQ_DISP_TOTAL_CD,
            NVL(CD.ESTQ_DISP_CD15, 0) AS ESTQ_DISP_CD15,
            NVL(CD.ESTQ_DISP_CD16, 0) AS ESTQ_DISP_CD16,
            NVL(CD.ESTQ_DISP_CD50, 0) AS ESTQ_DISP_CD50,
            NVL(V.QTD_VDA_30D, 0) AS VDA_30D_QTD,
            NVL(V.VLR_VDA_30D, 0) AS VDA_30D_VALOR,
            NVL(V.MEDIA_VDA_DIA, 0) AS MEDIA_VDA_DIA,
            NVL(PC.QTD_PEND_COMPRA, 0) AS PEND_COMPRA_FORNEC,
            NVL(PT.QTD_PEND_TRANSF_CD, 0) AS PEND_EXPEDICAO_CD,
            NVL(TR.QTD_EM_TRANSITO, 0) AS EM_TRANSITO_CD_LOJA,
            (NVL(PC.QTD_PEND_COMPRA, 0) + NVL(PT.QTD_PEND_TRANSF_CD, 0) + NVL(TR.QTD_EM_TRANSITO, 0)) AS TOTAL_PEND_RECEBER
        FROM MRL_PRODUTOEMPRESA PE
        INNER JOIN MAX_EMPRESA ME ON ME.NROEMPRESA = PE.NROEMPRESA
        INNER JOIN PRODUTOS_FILTRO PF ON PF.SEQPRODUTO = PE.SEQPRODUTO
        LEFT JOIN CTE_DEPARTAMENTO DEP ON DEP.SEQFAMILIA = PF.SEQFAMILIA
        LEFT JOIN FORNECEDOR_PRINCIPAL FP ON FP.SEQFAMILIA = PF.SEQFAMILIA
        LEFT JOIN PONTOS_EXTRAS PX ON PX.SEQPRODUTO = PE.SEQPRODUTO AND PX.NROEMPRESA = PE.NROEMPRESA
        LEFT JOIN VENDAS_30D V ON V.SEQPRODUTO = PE.SEQPRODUTO AND V.NROEMPRESA = PE.NROEMPRESA
        LEFT JOIN ESTOQUE_CD CD ON CD.SEQPRODUTO = PE.SEQPRODUTO
        LEFT JOIN PENDENTE_COMPRA PC ON PC.SEQPRODUTO = PE.SEQPRODUTO AND PC.NROEMPRESA = PE.NROEMPRESA
        LEFT JOIN PENDENTE_TRANSF_CD PT ON PT.SEQPRODUTO = PE.SEQPRODUTO AND PT.NROEMPRESA = PE.NROEMPRESA
        LEFT JOIN TRANSITO_CD_LOJA TR ON TR.SEQPRODUTO = PE.SEQPRODUTO AND TR.NROEMPRESA = PE.NROEMPRESA
        WHERE PE.NROEMPRESA IN (1, 2, 3, 4, 5, 6, 7, 8, 11, 12, 13, 14, 17, 18)
          AND PE.STATUSCOMPRA = 'A'
          AND (NVL(:NR1, 0) = 0 OR PE.NROEMPRESA = :NR1)
    ),
    BASE_CALCULADA AS (
        SELECT /*+ MATERIALIZE */
            B.NROEMPRESA AS COD_LOJA,
            B.SEQPRODUTO AS COD_PRODUTO,
            B.DESCRICAO_PRODUTO,
            B.DEPARTAMENTO,
            B.SECAO,
            B.NOME_COMPRADOR AS COMPRADOR,
            B.COD_FORNECEDOR || ' - ' || B.FORNECEDOR_PRINCIPAL AS FORNECEDOR_PRINCIPAL,
            B.FORMA_ABASTECIMENTO,
            B.EMB_COMPRA,
            B.EMB_TRANSF,
            B.ESTQ_DISP_LOJA,
            B.ESTQ_FISICO_LOJA,
            B.ESTQ_RESERVADO_LOJA,
            B.ESTQ_MIN_PADRAO,
            B.ESTQ_MAX_PADRAO,
            B.ESTQ_MIN_PONTO_EXTRA,
            B.ESTQ_MAX_PONTO_EXTRA,
            B.PONTOS_EXTRAS_ATIVOS,
            B.ESTQ_MIN_TOTAL,
            B.ESTQ_MAX_TOTAL,
            B.ESTQ_DISP_TOTAL_CD,
            B.ESTQ_DISP_CD15,
            B.ESTQ_DISP_CD16,
            B.ESTQ_DISP_CD50,
            B.VDA_30D_QTD,
            B.VDA_30D_VALOR,
            B.MEDIA_VDA_DIA,
            CASE
                WHEN B.MEDIA_VDA_DIA > 0 THEN ROUND(B.ESTQ_DISP_LOJA / B.MEDIA_VDA_DIA, 1)
                WHEN B.ESTQ_DISP_LOJA > 0 THEN 999
                ELSE 0
            END AS DIAS_ESTOQUE_LOJA,
            CASE
                WHEN B.MEDIA_VDA_DIA > 0 THEN ROUND((B.ESTQ_DISP_LOJA + B.ESTQ_DISP_TOTAL_CD) / B.MEDIA_VDA_DIA, 1)
                WHEN (B.ESTQ_DISP_LOJA + B.ESTQ_DISP_TOTAL_CD) > 0 THEN 999
                ELSE 0
            END AS DIAS_ESTOQUE_REDE,
            B.PEND_COMPRA_FORNEC,
            B.PEND_EXPEDICAO_CD,
            B.EM_TRANSITO_CD_LOJA,
            B.TOTAL_PEND_RECEBER,
            CASE
                WHEN B.MEDIA_VDA_DIA > 0 THEN ROUND((B.ESTQ_DISP_LOJA + B.TOTAL_PEND_RECEBER) / B.MEDIA_VDA_DIA, 1)
                WHEN (B.ESTQ_DISP_LOJA + B.TOTAL_PEND_RECEBER) > 0 THEN 999
                ELSE 0
            END AS DIAS_COB_COM_PENDENTES,
            CASE
                WHEN B.ESTQ_DISP_LOJA <= 0 AND B.TOTAL_PEND_RECEBER <= 0 AND B.ESTQ_DISP_TOTAL_CD <= 0 THEN '1 - RUPTURA CRITICA (LOJA E CD ZERADOS / SEM PEDIDO)'
                WHEN B.ESTQ_DISP_LOJA <= 0 AND B.TOTAL_PEND_RECEBER <= 0 AND B.ESTQ_DISP_TOTAL_CD > 0 THEN '2 - RUPTURA EM LOJA (TEM SALDO NO CD - GERAR PEDIDO)'
                WHEN B.ESTQ_DISP_LOJA <= 0 AND B.TOTAL_PEND_RECEBER > 0 THEN '3 - RUPTURA COM PEDIDO/TRANSITO A CAMINHO'
                WHEN B.ESTQ_DISP_LOJA > 0 AND B.ESTQ_DISP_LOJA < B.ESTQ_MIN_TOTAL AND B.TOTAL_PEND_RECEBER <= 0 AND B.ESTQ_DISP_TOTAL_CD > 0 THEN '4 - ABAIXO DO MINIMO (TEM SALDO NO CD / SEM PEDIDO)'
                WHEN B.ESTQ_DISP_LOJA > 0 AND B.ESTQ_DISP_LOJA < B.ESTQ_MIN_TOTAL AND B.TOTAL_PEND_RECEBER <= 0 AND B.ESTQ_DISP_TOTAL_CD <= 0 THEN '5 - ABAIXO DO MINIMO (CD ZERADO / SEM PEDIDO COMPRA)'
                WHEN B.ESTQ_DISP_LOJA > 0 AND B.ESTQ_DISP_LOJA < B.ESTQ_MIN_TOTAL AND B.TOTAL_PEND_RECEBER > 0 THEN '6 - ABAIXO DO MINIMO (COM PEDIDO/TRANSITO A CAMINHO)'
                WHEN B.ESTQ_DISP_LOJA > 0 AND B.MEDIA_VDA_DIA > 0 AND (B.ESTQ_DISP_LOJA / B.MEDIA_VDA_DIA) < 7 AND B.TOTAL_PEND_RECEBER <= 0 THEN '7 - ALERTA RUPTURA (COBERTURA < 7 DIAS / SEM PEDIDO)'
                WHEN B.ESTQ_MAX_TOTAL > 0 AND B.ESTQ_DISP_LOJA > B.ESTQ_MAX_TOTAL THEN '9 - EXCESSO DE ESTOQUE (> MAXIMO)'
                ELSE '8 - REGULAR / NORMAL'
            END AS STATUS_RUPTURA
        FROM BASE_DADOS B
    )
    SELECT
        C.COD_LOJA,
        C.COD_PRODUTO,
        C.DESCRICAO_PRODUTO,
        C.DEPARTAMENTO,
        C.SECAO,
        C.COMPRADOR,
        C.FORNECEDOR_PRINCIPAL,
        C.FORMA_ABASTECIMENTO,
        C.EMB_COMPRA,
        C.EMB_TRANSF,
        C.ESTQ_DISP_LOJA,
        C.ESTQ_FISICO_LOJA,
        C.ESTQ_RESERVADO_LOJA,
        C.ESTQ_MIN_PADRAO,
        C.ESTQ_MAX_PADRAO,
        C.ESTQ_MIN_PONTO_EXTRA,
        C.ESTQ_MAX_PONTO_EXTRA,
        C.PONTOS_EXTRAS_ATIVOS,
        C.ESTQ_MIN_TOTAL,
        C.ESTQ_MAX_TOTAL,
        C.ESTQ_DISP_TOTAL_CD,
        C.ESTQ_DISP_CD15,
        C.ESTQ_DISP_CD16,
        C.ESTQ_DISP_CD50,
        C.VDA_30D_QTD,
        C.VDA_30D_VALOR,
        C.MEDIA_VDA_DIA,
        C.DIAS_ESTOQUE_LOJA,
        C.DIAS_ESTOQUE_REDE,
        C.PEND_COMPRA_FORNEC,
        C.PEND_EXPEDICAO_CD,
        C.EM_TRANSITO_CD_LOJA,
        C.TOTAL_PEND_RECEBER,
        C.DIAS_COB_COM_PENDENTES,
        C.STATUS_RUPTURA
    FROM BASE_CALCULADA C
    WHERE (
        NVL(TRIM(:LT2), '0') IN ('0', 'NENHUM', '')
        OR NOT REGEXP_LIKE(
            REPLACE(TRANSLATE(UPPER(C.STATUS_RUPTURA), 'ÁÉÍÓÚÀÈÌÒÙÃÕÂÊÎÔÛÇ', 'AEIOUAEIOUAOAEIOUC'), ' ', ''),
            REPLACE(REPLACE(TRANSLATE(UPPER(TRIM(:LT2)), 'ÁÉÍÓÚÀÈÌÒÙÃÕÂÊÎÔÛÇ', 'AEIOUAEIOUAOAEIOUC'), ' ', ''), ',', '|'),
            'i'
        )
    )
)
ORDER BY
    STATUS_RUPTURA ASC,
    COD_LOJA ASC,
    DEPARTAMENTO ASC,
    DESCRICAO_PRODUTO ASC
```

## 3. Variáveis para Cadastrar em `Var - F7`

| Variável | Tipo | Descrição | Valor Padrão | Instrução |
| :--- | :--- | :--- | :--- | :--- |
| **`LT1`** | Literal | Códigos dos Produtos (ex: 1001, 1002) | `0` | Digite os códigos separados por vírgula ou `0` para todos |
| **`LT2`** | Literal | Expurgo de Status Ruptura (ex: 8, 9 ou 0) | `0` | Digite os números dos status a ocultar (ex: `8, 9` para ocultar Regular e Excesso) ou `0` para exibir todos |
| **`NR1`** | Numérico | Número da Loja (0 = Todas) | `0` | Informe a loja específica ou `0` para todas as lojas |

---

## 4. Passo a Passo de Configuração no Totvs Consinco

1. Acesse o **Totvs Consinco > SGI > Consulta Criação**.
2. Cole o código do **SQL Principal** na área de texto da consulta.
3. Clique no botão **`Var - F7`** no menu superior.
4. Cadastre as 3 variáveis:
   - **`LT1`** (Literal): Descrição `Códigos dos Produtos (ex: 1001, 1002)`, Valor Padrão `0`.
   - **`LT2`** (Literal): Descrição `Expurgo de Status Ruptura (ex: 8, 9)`, Valor Padrão `0` (ou `8, 9`).
   - **`NR1`** (Numérico): Descrição `Número da Loja (0 = Todas)`, Valor Padrão `0`.
5. Clique em **OK** para salvar os parâmetros e pressione **Executar (`F8`)**.
6. A janela de filtro abrirá apenas com os campos diretos (`LT1`, `LT2`, `NR1`), sem nenhuma lista suspensa.
