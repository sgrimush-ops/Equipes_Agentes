## Manual: RELATORIO_DE_ANALISE_DE_ESTOQUE_-_PLENO-KW_.pdf

RELATÓRIO DE ANÁLISE DE
ESTOQUE - PLENO-KW
1- Acesso ao Pleno-KW
Neste procedimento, será apresentado como realizar o acesso ao sistema
Pleno-KW e iniciar a utilização da plataforma.
1) Entrar pelo link: http://baklizi.cloudprotect.info:8146/usuario do seu
navegador de preferência.
2) Informe seu usuário e senha e clique em acessar.

2) Navegação no Sistema
Este procedimento apresenta uma breve visão da navegação no sistema Pleno-KW,
demonstrando os principais menus disponíveis e como localizar as funcionalidades
necessárias para realizar os procedimentos.
1) Acesse o sistema
Após realizar o acesso ao Pleno-KW, será apresentada a tela principal do sistema.
No lado esquerdo da tela está localizado o menu de navegação, onde ficam
organizados os principais módulos.
2) Acesse o módulo desejado
Para realizar cada procedimento, é necessário localizar o módulo correspondente no menu
lateral e acessar suas respectivas opções.

1. Acessando o Relatório de Análise de Estoque
Para iniciar o procedimento, no menu lateral do Pleno KW, acesse:
Estoque → Relatórios → Análise de Estoque
Ao selecionar Análise de Estoque, será aberta a tela de filtros do relatório, onde
poderão ser definidos os critérios utilizados para gerar a análise.

2. Filtros do relatório
A tela de Relatório de Análise de Estoque possui diversos filtros que permitem limitar e
direcionar as informações apresentadas no relatório. Os filtros podem ser utilizados
individualmente ou em conjunto, de acordo com o tipo de análise que será realizada.
Nesta etapa, serão apresentados os principais campos disponíveis e sua finalidade. Nos
próximos passos, cada grupo de opções poderá ser explicado separadamente.
1. Período da análise
Os primeiros campos são Data Inicial e Data Final.
Data Inicial: determina a data a partir da qual as movimentações serão
consideradas.
Data Final: determina a data limite da análise.
O período deve ser preenchido de acordo com o intervalo que se deseja consultar.
Exemplo: para analisar as movimentações ocorridas durante o mês, informe o primeiro e o
último dia do período desejado.
2. Segmento O campo Segmento permite selecionar o segmento que será considerado na análise.
Por padrão, pode aparecer como Todos, permitindo que o relatório considere todos os
segmentos disponíveis. Caso seja necessário realizar uma análise mais específica,
selecione o segmento correspondente.
3. Filial
O campo Filial permite determinar em qual filial os dados serão consultados.
É possível manter a opção Todas para realizar uma análise geral ou selecionar uma filial
específica para verificar somente as movimentações relacionadas àquela unidade.

4. Família
O campo Família permite filtrar as mercadorias de acordo com a família cadastrada no
sistema.
Esse filtro é útil quando a análise precisa ser direcionada para um determinado grupo de
produtos, evitando a necessidade de consultar todas as mercadorias disponíveis.
5. Mercadoria
O campo Mercadoria permite localizar uma mercadoria específica para a análise. A
pesquisa pode ser realizada utilizando informações como:
Código interno;
Descrição;
EAN;
Código alfanumérico.
Caso o campo seja deixado sem preenchimento, a análise poderá considerar as
mercadorias de acordo com os demais filtros selecionados.
6. Fornecedor
O campo Fornecedor permite filtrar a análise de acordo com o fornecedor responsável pelas
mercadorias.
A pesquisa pode ser realizada utilizando informações como CNPJ, CPF, nome ou nome
fantasia do fornecedor.
Esse filtro é útil para analisar as movimentações relacionadas aos produtos fornecidos por
uma determinada empresa.
7. Origem da Mercadoria
O campo Origem da Mercadoria permite selecionar a origem dos produtos que serão
considerados no relatório.
Caso não seja necessário restringir a análise por esse critério, o campo pode
permanecer como Selecione.
8. Finalidade da Mercadoria
O campo Finalidade da Mercadoria define qual finalidade dos produtos será
considerada na análise.
Essa opção permite direcionar o relatório para mercadorias com uma finalidade
específica. No exemplo apresentado, a opção selecionada é Revenda.

9. Status da Mercadoria
O campo Status Mercadoria permite filtrar os produtos de acordo com sua situação no
sistema.
É possível, por exemplo, manter a opção Todos para considerar todas as situações ou
selecionar um status específico para restringir os resultados.
10. Status de Compra
O campo Status Compra permite determinar a situação de compra das mercadorias que serão
consideradas na análise.
Assim como nos demais filtros, a opção deve ser selecionada somente quando for
necessário restringir o relatório a uma determinada situação de compra.
11. Marca
O campo Marca permite realizar a análise considerando uma marca específica.
Esse filtro é útil para consultar as movimentações de determinado fabricante ou marca sem
precisar analisar todas as mercadorias cadastradas.
12. Classificação Mercadológica
Por fim, o campo Classificação mercadológica permite selecionar uma classificação
específica para direcionar a análise.
Esse recurso é utilizado quando se deseja consultar produtos pertencentes a
determinada categoria ou classificação cadastrada no sistema.
Observação: os campos apresentados nesta etapa são filtros da análise. Eles devem
ser preenchidos conforme o objetivo da consulta. Não é necessário preencher todos
os campos; quanto mais filtros forem utilizados, mais específica será a análise
gerada.

13. Tipos de Movimentação
A seção Tipo de Movimentação permite definir quais movimentações de estoque serão
consideradas na análise. É possível selecionar uma ou mais opções, de acordo com o
objetivo do relatório.
Opção "TODOS"
A opção TODOS permite selecionar todas as movimentações disponíveis de uma só vez.
Quando essa opção é utilizada, o relatório considera todos os tipos de movimentação cadastrados,
sem a necessidade de marcar cada opção individualmente.
Movimentações de Entrada
NF Compra + NF Compra Importação + NF Contra Nota (Compras): considera as
movimentações relacionadas à entrada de mercadorias por meio de compras,
incluindo compras de importação e operações realizadas por contra nota.
NF Transferência Entrada: considera as mercadorias que entraram na filial por meio de
uma transferência entre unidades.
Boletim Entrada: considera entradas de mercadorias registradas por meio de
boletim de entrada.
Movimentações de Venda e Saída
Cupom + NF Venda + NF Remessa Venda Futura (Vendas): considera as
movimentações relacionadas às vendas realizadas, incluindo cupons, notas fiscais de
venda e remessas referentes a vendas futuras.
NF Transferência Saída: considera as mercadorias que saíram da filial por meio de
uma transferência para outra unidade.
Boletim Saída: considera as movimentações de saída registradas por meio de
boletim.
Devoluções
NF Devolução Venda: considera as mercadorias que retornaram ao estoque em
decorrência de uma devolução de venda.
NF Devolução Compra: considera as devoluções de mercadorias realizadas para
fornecedores.

Quebras e Baixas
NF Quebra + NF Baixa por Uso e Consumo (Baixas): considera movimentações
relacionadas a quebras de mercadorias e baixas realizadas por uso e consumo.
Observação: os tipos de movimentação devem ser selecionados de acordo com o
objetivo da consulta. Caso seja necessário realizar uma análise geral, pode-se
utilizar a opção TODOS. Para uma análise específica, selecione somente as
movimentações que deseja considerar no relatório.
3. Agrupamento do Relatório
Antes de gerar o relatório, é possível definir como as informações serão organizadas no
resultado da consulta. O campo Agrupamento permite escolher uma categoria para
organizar os produtos apresentados.
As opções disponíveis são:
Departamento: organiza as mercadorias de acordo com o departamento ao qual
pertencem.
Seção: agrupa os produtos conforme a seção cadastrada.
Grupo: organiza as mercadorias de acordo com o grupo de produtos.
Subgrupo: apresenta os produtos separados conforme seus subgrupos.
Mercadoria: organiza o resultado diretamente pelas mercadorias consultadas.

4. Gerar o Relatório
Após configurar os filtros e escolher a forma de agrupamento, basta finalizar a
consulta para visualizar o relatório.
● Confira os filtros selecionados.
● Escolha o Agrupamento desejado.
● Clique em Gerar.
● O sistema irá processar as informações e apresentar o Relatório de Estoque
conforme os filtros definidos.
Importante: caso seja necessário refazer a consulta com outros parâmetros, utilize a
opção Limpar para remover os filtros selecionados e iniciar uma nova pesquisa.
5. Interpretação
Após gerar o relatório, será apresentada uma tabela que permite analisar a
movimentação do estoque dentro do período selecionado, comparando o estoque existente
no início do período com as entradas, saídas e o estoque final. No exemplo, o período
analisado é de 01/08/2026 a 28/08/2026, com os dados agrupados por departamento.
Agrupamento por Departamento
Como o relatório foi configurado para Agrupado por Depto, as informações são apresentadas
separadamente para cada departamento. Isso permite acompanhar quais departamentos
tiveram maiores entradas, saídas ou alterações no estoque durante o período.

Estoque Inicial
Apresenta a quantidade e o valor das mercadorias que estavam disponíveis no estoque no
início do período selecionado.
Quantidade: número de unidades existentes.
Valor: valor correspondente a esse
estoque.
No exemplo, o total da loja iniciou o
período com 231.271 unidades,
correspondentes a R$ 10.199.307,26.
Entradas
Mostra as mercadorias que entraram no estoque durante o período, juntamente com suas
quantidades e valores.
No relatório apresentado, foram
registradas 32.866 unidades de
entrada, totalizando R$ 339.703,08.

Saídas
Apresenta as mercadorias que saíram do estoque durante o período analisado,
mostrando tanto a quantidade quanto o valor correspondente.
No exemplo, ocorreram 123.245
unidades de saída, representando R$
1.658.414,23.
Estoque Final
Mostra a quantidade e o valor das mercadorias que permaneceram em estoque ao final do
período.
No total da loja, o estoque final
apresentado foi de 204.745 unidades,
com valor de R$ 9.947.989,68.

Observação: os valores apresentados neste tutorial são apenas uma demonstração
baseada nos filtros utilizados no exemplo. Os resultados do relatório podem variar
conforme o período, filial, finalidade, status e tipos de movimentação selecionados.
Salvamento do relatório
Para finalizar o procedimento, no canto inferior direito da tela estão disponíveis duas
opções para salvar o relatório:
PDF: gera o relatório em formato PDF, sendo indicado quando for necessário
visualizar, imprimir ou compartilhar o relatório mantendo sua formatação.
CSV: gera o relatório em formato CSV, permitindo trabalhar os dados em planilhas e
realizar análises ou filtros posteriormente.
Selecione a opção desejada de acordo com a finalidade do relatório.

Relatório de Análise de Vendas
Para acessar o relatório, siga o caminho:
Financeiro → Relatórios → Análise de Vendas
Ao acessar, será apresentada a tela de filtros do Relatório de Análise de Vendas, onde é
possível definir quais informações serão consideradas na consulta.

A tela está dividida em duas partes principais:
Filtro: onde são definidos os critérios da pesquisa, como filial, período, mercadoria,
fornecedor e classificação mercadológica.
Agrupamento: permite escolher como os resultados do relatório serão organizados.
Filtros
Filial
Permite selecionar a filial que será considerada na análise. É possível escolher uma filial
específica ou “Todas”, conforme as opções disponíveis no sistema.
Data Inicial / Data Final
Define o período da análise de vendas. A Data Inicial indica o começo do período e a Data
Final indica o encerramento. Esses campos permitem analisar as vendas realizadas dentro do

Permite pesquisar por uma mercadoria específica, podendo utilizar informações como Cód.

relacionadas a um determinado fornecedor.
Classificação mercadológica
Permite selecionar uma classificação mercadológica para restringir a análise às
mercadorias pertencentes à classificação escolhida.

Agrupamento
Além dos filtros, a tela possui a opção “Agrupamento”, que permite definir como os
resultados serão organizados no relatório. No exemplo apresentado, a opção
selecionada é Departamento.
Depois de preencher os filtros e definir o agrupamento desejado, basta clicar em
“Gerar” para visualizar o relatório.
Observação: as informações apresentadas na imagem são utilizadas apenas como exemplo
para este tutorial. Os dados e resultados do relatório podem variar
conforme os filtros e informações cadastradas no sistema.

Interpretação do Relatório de Análise de Vendas
O relatório apresenta os resultados das vendas organizados por departamento, permitindo
comparar valores orçados, realizados, promoções, desvios, descontos e margens. No
exemplo, o agrupamento foi feito por Departamento.
Mercadorias / Orçamento
Mercadorias: apresenta os departamentos que estão sendo analisados, como
Bebidas Nacionais, Mercearia Nacional, Importados, Vestuário Nacional, entre
outros.
Orçamento: mostra os valores que haviam sido previstos para as vendas. No
exemplo apresentado, os valores de orçamento aparecem zerados, indicando que não
houve orçamento preenchido para esse período.
Acumulado / Mês
Acumulado: representa o valor acumulado do orçamento ou das vendas realizadas no
período considerado.
Mês: apresenta o valor correspondente ao mês analisado.

Realizado / Margem Efetiva
Realizado: apresenta o valor que foi efetivamente vendido no período. No total da loja do
exemplo, foram realizadas vendas de R$ 878.630,47.
Margem Efetiva: mostra a margem obtida nas vendas, apresentando tanto o valor em R$
quanto o percentual. No total da loja, a margem efetiva foi de R$ 59.594,41, correspondente
a 6,78%.
% Part / Acumulado
% Part: demonstra a participação do departamento dentro do total realizado.
Acumulado: apresenta o valor acumulado das vendas realizadas, permitindo visualizar o desempenho
de cada departamento ao longo do período.
Promoção / Margem Efetiva
Promoção: apresenta os valores relacionados às vendas realizadas em promoções,
permitindo analisar quanto foi movimentado nesse tipo de venda.
Margem Efetiva: demonstra a margem obtida sobre as vendas promocionais, tanto em R$
quanto em %.

Desvio

resultado alcançado, ajudando a identificar diferenças no desempenho.
R$ Acumulado: demonstra essa diferença em valores monetários, permitindo
visualizar quanto ficou acima ou abaixo do valor de referência.
Descontos PLU
Venda Bruta: apresenta o valor das vendas antes da aplicação dos descontos.
Venda Líquida: apresenta o valor das vendas após os descontos considerados pelo sistema.
R$ Desconto: demonstra o valor total concedido em descontos PLU.

Atingido do Total / Venda Projetada
Atingido do Total: indica o percentual do total que foi atingido pelas vendas,
permitindo acompanhar o desempenho em relação ao objetivo estabelecido.
Venda Projetada: apresenta uma projeção de vendas para o período, quando
houver dados necessários para esse cálculo.
% Ano Anterior
Indica o percentual relacionado à comparação das vendas com o mesmo período do ano
anterior, permitindo analisar a evolução ou redução do desempenho em relação ao período
anterior.
Observação: os dados e valores apresentados neste relatório são apenas exemplos
utilizados para demonstrar a interpretação do relatório. Os resultados reais podem variar de
acordo com os filtros, período e informações cadastradas no sistema.

2. Filtros do Relatório de Compras
Os filtros permitem definir quais compras serão consideradas na consulta, podendo limitar
os resultados por período, filial, mercadoria ou fornecedor.
Período Inicial
Define a data de início da consulta. O sistema considerará as compras realizadas a partir
dessa data.
Período Final
Define a data final da consulta. Junto com o período inicial, determina o intervalo em que
as compras serão analisadas.
Filial

Fornecedor
Permite filtrar as compras de acordo com um fornecedor específico. A pesquisa pode ser

● Família: permite selecionar uma determinada família de produtos para limitar os
resultados do relatório.
● Marca: possibilita filtrar a movimentação por uma marca específica.
● Fornecedor: permite informar um fornecedor através de CNPJ, CPF, nome ou nome
fantasia, restringindo o relatório às mercadorias relacionadas a esse fornecedor.
● Status Compra: permite selecionar o status de compra que deverá ser considerado na
consulta.
● Curva ABC: possibilita filtrar as mercadorias de acordo com sua classificação na
Curva ABC.
● Finalidade Principal: permite selecionar a finalidade principal da mercadoria para
restringir os resultados.
● Origem da Mercadoria: permite selecionar a origem atribuída às mercadorias que
serão consideradas no relatório.
● UF Origem: permite definir o estado de origem das mercadorias. A opção Todos
mantém a consulta sem restrição por estado.
● Subtrai Devolução Venda: ao marcar essa opção, as devoluções de venda serão
consideradas de forma a serem subtraídas no resultado da movimentação.

● Estoque sem troca: permite considerar na consulta as movimentações relacionadas a
mercadorias que não possuem troca de estoque.
● Ignorar Transferências: quando selecionado, as transferências entre locais/filiais
serão desconsideradas no relatório.
● Classificação mercadológica: permite selecionar uma classificação mercadológica
específica para restringir os produtos apresentados na consulta.
Observação: os filtros não precisam necessariamente ser todos preenchidos. Deve
se utilizar apenas aqueles que forem necessários para chegar ao resultado
desejado. Quanto mais filtros forem aplicados, mais específica será a consulta
realizada.
Classificação mercadológica
A opção Classificação mercadológica permite selecionar uma classificação específica para
filtrar as mercadorias que serão consideradas no relatório.
Ao selecionar uma classificação, o sistema apresentará apenas as movimentações
relacionadas às mercadorias pertencentes à categoria escolhida. Caso não seja
necessário restringir o relatório por classificação, mantenha a opção como
“Selecionar”.
4. Agrupamento do Relatório
Antes de gerar o relatório, é possível definir como as informações serão organizadas no
resultado da consulta. O campo Agrupamento permite escolher uma categoria para
organizar os produtos apresentados.
As opções disponíveis são:
● Departamento: organiza as mercadorias de acordo com o departamento ao qual
pertencem.
● Seção: agrupa os produtos conforme a seção cadastrada.
● Grupo: organiza as mercadorias de acordo com o grupo de produtos.
● Subgrupo: apresenta os produtos separados conforme seus subgrupos.
● Mercadoria: organiza o resultado diretamente pelas mercadorias consultadas.
Observação: a escolha do agrupamento depende da forma como se deseja visualizar
o relatório. Por exemplo, ao selecionar Departamento, os produtos serão
apresentados separados por seus respectivos departamentos, facilitando a análise
de cada categoria.
