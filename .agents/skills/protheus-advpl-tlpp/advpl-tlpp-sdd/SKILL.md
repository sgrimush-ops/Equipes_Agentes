# SKILL.md — advpl-tlpp-sdd

## Descrição
Skill para padronização, automação e documentação de processos de desenvolvimento, migração e manutenção em Protheus/AdvPL/TLPP. Fornece checklists, templates e guias para todas as etapas do ciclo de vida do software, integrando com agentes de code review, geração de documentação e migração.

## Exemplos de uso
- Gerar checklist de início de projeto
- Consultar padrões de granularização de tarefas
- Validar entregas com critérios objetivos
- Registrar discussões técnicas e decisões
- Mapear sistemas legados para migração
