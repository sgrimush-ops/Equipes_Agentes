# Skills de Agente AdvPL/TLPP

Coleção de skills para automação, geração de código, revisão, testes e documentação no ecossistema TOTVS Protheus ERP (AdvPL/TLPP).

## Categorias
- Geração de código (MVC, REST, Entry Points, Queries)
- Migração e modernização (AdvPL → TLPP)
- Qualidade e revisão (Code Review, SQL Review, Refatoração)
- Testes automatizados (TIR)
- Documentação e planejamento (ProtheusDOC, Context Map, Data Dictionary)

Consulte cada SKILL.md para instruções detalhadas, exemplos e padrões.
